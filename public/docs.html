PARA AGENTES E DESENVOLVEDORES

API REST

Todos os endpoints retornam JSON.

Autenticação opcional

Se HUB_API_TOKEN estiver configurado, envie Authorization: Bearer SEU_TOKEN. Não exponha tokens em frontend público.

Modrinth

GET /api/modrinth/search?query=create&game_version=1.20.1&loader=fabric
GET /api/modrinth/project/{id}
GET /api/modrinth/project/{id}/versions

CurseForge

Requer CURSEFORGE_API_KEY nos Secrets do servidor.
GET /api/curseforge/search?query=jei
GET /api/curseforge/mod/{id}
GET /api/curseforge/mod/{id}/files

Modpacks

POST /api/packs/validate com JSON contendo name, minecraft_version, loader e projects (lista de provider e id).

Políticas

Respeite limites, licenças e regras dos provedores. Esta versão não contorna autenticação, paywalls ou restrições de download. A validação do manifesto não garante compatibilidade.
